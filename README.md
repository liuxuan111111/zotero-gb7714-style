# Zotero 国标引用格式 · zotero-gb7714

> 让 Zotero 一键生成符合 GB/T 7714 的中文参考文献引用样式。

## 问题

Zotero 默认引用样式不符合中文期刊要求的 GB/T 7714 格式，参考文献排版格式不统一，逐条手动调整费时费力。

## 解决方案

编写 GB/T 7714 引用样式文件 `standard.csl`，导入 Zotero 样式管理器，并按正文首次引用顺序整理参考文献输出。

## 结果

Zotero 一键生成符合国标的参考文献，格式统一规范，投稿中文期刊无需再手动调整引用格式。

## 文件清单

- `standard.csl` — GB/T 7714 引用样式
- `zotero引用参考文献格式.docx` — 使用效果示例
- `正文首次引用顺序.docx` — 顺序整理说明

## 使用方式

把 `.csl` 放入 Zotero 的 `styles` 文件夹，重启后在「首选项 → 引用 → 样式」中启用。
